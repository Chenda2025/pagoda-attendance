កំណត់ប្លងសាលាឆាន់

បញ្ចូលឈ្មោះជួរ និងលំដាប់ (១ = ខាងលើ)

    កំណត់ចំនួនតុក្នុងមួយជួរ · បញ្ឈរ (៨កន្លែង) ឬ ផ្តេក (៦កន្លែង) · អាចដាក់តុជាប់គ្នា

    កំណត់ចំនួនកន្លែងក្នុងមួយតុ · អាចទុកទទេ

    ប្លង់ត្រូវបានកំណត់ — ចុចលើកន្លែងទទេដើម្បីជ្រើសឈ្មោះ ឬ «រៀបតាមអក្សរ»

      កែជួរ

      កែតុ

      ចុចលើកន្លែងដើម្បីជ្រើសទីតាំង (ត្រូវជ្រើសឱ្យគ្រប់ចំនួន)

      លុបតុ

      សម្អាតតុ

      ឈ្មោះលើកន្លែងនៃតុនេះនឹងត្រូវសម្អាត — តុនៅដដែល

      ណែនាំ — ប្លងសាលាឆាន់

      ទំព័រនេះប្រើសម្រាប់រៀបចំតុ និងកន្លែងអង្គឆាន ក្នុងសាលាឆាន់ រួចជ្រើសឈ្មោះសង្ឃតាមកន្លែង។

      របៀបប្រើ

      1. កំណត់ប្លង់ — បង្កើតជួរ តុ (ផ្តេក ៦ / បញ្ឈរ ៨) និងចំនួនកន្លែង
      2. រូបតុលើផ្ទាំង — ចុចកន្លែងទទេ ដើម្បីជ្រើសឈ្មោះសង្ឃ
      3. រៀបតាមអក្សរ — បំពេញកន្លែងទទេតាមលំដាប់អក្ខរក្រមដោយស្វ័យប្រវត្តិ
      4. រក្សាទុក — រក្សាទុកប្លង់ទៅមូលដ្ឋានទិន្នន័យ

      ប៊ូតុង «កែប្រែ» ខាងលើ

      • បន្ថែម — បង្ហាញប៊ូតុងបន្ថែមជួរ / តុ (កំណត់ទីតាំង)
      • កែប្រែ — កែជួរ/តុ និងទីតាំងកន្លែង
      • ជ្រើស / ប្តូរឈ្មោះ — ចុចកន្លែងលើតុដើម្បីដាក់ឈ្មោះ
      • លុប / សម្អាត — លុបជួរ/តុ ឬ សម្អាតឈ្មោះ
      • បិទកែប្រែ — លាក់ប៊ូតុងគ្រប់គ្រងលើជួរ

      ចុចឈ្មោះលើតុបានគ្រប់ពេល ដើម្បីកត់ អវត្តមាន / ច្បាប់ / យឺត (ដូចប្លង់អាសនៈ)។

      ប្រភេទតុ

      • ផ្តេក — អតិបរមា ៦ កន្លែង (លើ ក្រោម ឆ្វេង ស្តាំ)
      • បញ្ឈរ — អតិបរមា ៨ កន្លែង
      • បើកន្លែងតិចជាងអតិបរមា — ជ្រើសទីតាំងក្នុងគំរូតុពេលបន្ថែម/កែ

      តុក្នុងមួយជួរដាក់តាមជួរផ្តេកមួយ — អូស ឬ ស្គ្រុល ឆ្វេង–ស្តាំ ដើម្បីមើលតុបន្តបន្ទាប់។

      សុំច្បាប់

      ទាំងពីរ = ព្រឹកផង និង ថ្ងៃត្រង់ផង
